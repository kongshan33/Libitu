## Delivered behavior

- **P1:** `sound-rules-v2`, fixed GA target, 11 candidate kinds plus the separate Vowel duration entry, bounded subtype/anchor/alternative fields. The client accepts v1, explicitly maps old T/D and H elision, and migrates only the known coalescence rule. Unknown legacy assimilation keeps an unspecified subtype. Python/TS contract parity is tested. Both caches retain source/version isolation.
- **P2:** bounded deterministic candidates, with conditions and exact source spans. Relevant boundary phones must agree across all dictionary variants; unresolved phones are skipped. The reviewed `last`/`next` full-cluster/deletion pairs remain alternatives. Truncated pronunciation lists cannot supply false consensus. No audio or LLM requests were added. Exact rule coverage and sources are in the plan's implementation notes.
- **P3:** 12 filters in four labeled groups, subtype reset, explicit unsupported states, shared Detailed/Review components, word/phone/boundary anchors, two visible reading events plus `+N`, and grouped alternative realizations. Both voices' text cues are dashed. Native buttons and details support touch and keyboard. Filter context reserves layout space; body positions remain stable. Unrelated marks alone dim to 20%, restoring readability on focus/hover. Notes remain collapsed. Concealment covers cues, IPA, explanations, matching results and the selected directory sentence.
- **P4:** original vowel phone index/label/duration, voice/analysis provenance and quality gates. Reliable corresponding vowel sequences display separate raw values and an optional median word-pace normalization. One-sided and unmatched evidence stays separate. Saved legacy assessment pairs can supply explicitly labeled word totals; they never manufacture individual vowels. Empty historical takes cannot borrow current reference measurements. No phone timestamps, audio reanalysis or score changes were introduced.
- **P5:** root checks, unit/contract/rule regression, live browser interaction and visual inspection at 1400px and 390px.

## Reproduce

Run the normal Next development server on port 3000, then the local synthetic proxy:

```sh
node apps/web/tests/helpers/quick-browser-fixture.mjs
```

Use an available Playwright installation with Chrome. If Playwright is not in the local module path, set `LIBITU_PLAYWRIGHT_MODULE` to its installed module directory.

```sh
node apps/web/tests/ga-sound.browser.mjs
LIBITU_TEST_WIDTHS=1400,390 LIBITU_SCREENSHOT_DIR=output/playwright/ga-sound/timeline-regression node apps/web/tests/analysis-timeline.browser.mjs
node apps/web/tests/ga-sound-density.browser.mjs
```

The GA fixture invokes `apps/api/.venv/bin/python`; it requires the installed API environment and pinned vendored CMU dictionary. Generated local artifacts live in `output/playwright/ga-sound/`. Representative viewport captures and the compact browser result are retained beside this report. The fixed app navigation is visible in viewport images; fixture controls are excluded from the representative captures.

## Remaining coverage

Manner assimilation, general unstressed-vowel reduction, other elision, syllabic /m/ and positive voicing rules remain explanatory subtypes with explicit unsupported messages. Cross-word/complex-stress tapping, broad grammar inference, source accent identification and confirmed acoustic realization are outside this increment. Linguistic sources were checked against the finite rule conditions; no independent expert listening study or detector benchmark was performed.
