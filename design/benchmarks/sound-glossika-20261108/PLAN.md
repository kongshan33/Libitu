## 2. 保留三层标签，避免把规则教成听觉事实

每个音频片段记录三种不同内容：

1. **文字与词典参考**：实际说了哪些词、哪些词位有适用语境。用于找位置与比较基础读法。
2. **录音的 IPA**：教材原始 IPA 保留为 `ipa_book`；经核对该录音后另写 `ipa_heard`。它才是语音转 IPA 的训练答案。保留教材形式、规范化形式、修订人和修订原因。
3. **Sound 事件**：kind/subtype、词跨度、音频时间、基础音与实际音、present/absent/uncertain/not_applicable，以及竞争实现和标注来源。这里容纳全部 12 类；不同位置可多标签，同一辅音的替代实现不能全部标有。

音素转写训练可采用片段级 CTC，不要求先人工划出每个音素的边界；但输出可点击、可回放的 Sound 证据，需要额外的局部定位。模型的 CTC 尖峰或强制对齐生成的字典音素不能直接充当事件真值。

以 `better` 为例，若该条录音确实用了 [ɾ]，IPA 的答案必须保留 [ɾ]，同时记录词内 /t/ 的闪音事件；不能由普通 G2P 把它改回 /t/。同样，`can get` 的拼写只能产生检查 /n/ 的候选，实际 [n]、[ŋ]、其他实现或听不清，需要音频决定。

人工工作采用“核对已有标注”的方式：系统先呈现音频、教材 IPA 和待核对目标，标注者确认/修订/跳过，重点处理乱码、多读法、模型分歧和竞争实现。训练用标签可保留单人审校等级；用于最终效果声明的冻结测试子集需要独立复核与争议仲裁，不能把所有训练行都错误要求成双人金标。

## 3. IPA 规范化

先制定并版本化项目使用的音段及附标表，再生成训练标签：

- 保留 raw 书本标音；规范化在另一字段完成，可追溯到 PDF 页码和例句编号。
- 旧连字 `ʧ/ʤ/ʦ/ʣ` 可转为项目统一的 affricate 表示；模型序列与评测音段切分规则分别固定，不能将一个塞擦音的多个字符误计为多个独立错误。
- 组合字符使用明确的 Unicode 规范化流程；`ɫ` 与可组合表示、书本 `ʴ` 与 rhoticity 记法等需审定语义后映射，不能按相似字形替换。
- `⁼`、`ˀ`、`ṇ`、结合弧及细分送气/清化符号，不直接丢掉。区分可等价编码、独立属性、第一版不预测但保留的附标，以及需要扩展输出词表的情况。禁止使用 NFKC 等无差别兼容折叠来改变语音意义。
- 现有 ZIPA 词表本来就含 `ɾ`、`ʔ`、`m/n/ŋ`、送气、长音、鼻化、成音节和无可闻爆破等字符；三类试验不必因输出不到 [ɾ] 就先换整个模型或扩词表。
- 第一版优先确保项目所需的实际音段及必要附标准确，再评估更窄的全附标输出。书中的某位说话人、语体、合流选择不能定义为所有 GA 说话人必须采用的唯一读法。

## 4. 十二类如何使用本资料

下表是取样与标注方案，**不是已统计出的真实阳性数量**。

| Sound 类别 | 可优先检索的材料 | 所需训练/验证证据 |
|---|---|---|
| Linking | 短句、冠词章节 | 词边界实现与停顿/过渡；连续波形或 IPA 空格不能单独证明连读 |
| Coalescence | 短句中的 did/would/what + you | /t,d/+ /j/ 对应的实际融合，并补保留、省音、声门等竞争例 |
| Assimilation | can + get/come/be/park | /n/→[ŋ]/[m] 的目标处证据及同语境仍为 [n] 的反例 |
| Weakening | can、to、功能词短句 | 同一功能词强弱读及重音语境；字典中本来的 ə 不自动算弱化 |
| Reduced forms | going to、have to 等材料候选 | 实际短语版本与词汇/语法条件；先清点可用覆盖 |
| Elision | 短句 T/D/H 语境 | 省音与未释放、融合、声门替代分开；缺一个爆破或模型 token 不是省音证据 |
| T/D tap | 第 2 章 little/better/ladder/ready 等列表 | 词内 /t,d/→[ɾ]；跨词例另列，不混入首轮受限范围 |
| Glottalization | 含 [ʔ]/ˀ 的短句及 can/can’t | 替代、加强与无证据分开，核对局部声学线索 |
| Unreleased | 第 2 章及短句的相关附标 | 闭塞/释放的可听与可观察证据，不等同于辅音消失 |
| Syllabic | can、it’ll、able 等 | [n̩/l̩/m̩] 与 ə+C 对照；需核对实际有无元音核 |
| Voicing change | 教材清化/浊化附标例 | 基础音、局部有声性与部分/完整变化；不把不送气或闪音重复算作浊化 |
| Vowel length | 第 2 章同元音长短组 | 相似重音/语速/位置下、词尾清浊条件的对照；不由单个 ː 或固定毫秒阈值定义现象 |

所有类别都可以在整理时登记候选和实际证据，但第一轮模型实验仍集中在词内闪音、/t,d/+ /j/ 融合、/n/ 部位同化。其他九类按覆盖与验证进度逐项开放，不做一个凭 69 分钟资料宣称全覆盖的 12 分类器。送气、dark L、音质等可作为 IPA 辅助属性，不增加产品一级 chip。

## 5. 模型与训练路线

最新实验顺序：**共享审校数据 → Wav2Vec2Phoneme IPA SFT、WavLM Base+ 三类局部事件头、ZIPA large 基线对照**。这是用户要求开始准备数据前讨论的三项实验，取代最初的 ZIPA-only IPA 微调建议。Allophant 与已有四模型结果继续保留；不根据少数句子的直观观感宣告模型胜出。

**实验 A / IPA 任务**：在核对后的片段 IPA 上试 Wav2Vec2Phoneme 的监督式 CTC 微调，先核定目标词表与标签口径，再比较冻结编码器/输出头与逐步解冻少量高层的设置。未建立可训练标签与冻结评测前不启动训练，不预设使用 LoRA 或强化学习。

**实验 C / ZIPA 对照**：同一批音频增加 ZIPA large 原模型推理，比较 small、large 与 Wav2Vec2Phoneme 的局部错误。如果后续决定微调 ZIPA，使用训练 checkpoint；当前本地 ONNX 只是推理资产。先在支持的环境复现基线，不把 large 推理对照写成已完成的后训练。[ZIPA 官方代码](https://github.com/lingjzhu/zipa)

**实验 B / Sound 任务**：先用冻结 WavLM Base+ 编码器的局部音频特征训练小型目标事件头。文本规则找目标位置，人工核验窗口与实际实现；规则约束比较什么、归入哪个类别，声学模型判断实际发了什么。保留未变化、其他实现、质量不足等状态。初期三类分别评估，不靠字符串里出现任意 [ɾ]/[m]/[ŋ] 触发。是否共享 IPA 编码器、是否联合损失，在首个对照实验之后决定。

Allophant 在同一冻结测试音频上保留原配置作对照；其音素/属性后验是模型输出，不是已校准的现象置信度。若需要另行微调，单列实验，不能同时改变两个模型、词表与标签口径后再作因果比较。[Allophant 官方代码](https://github.com/kgnlp/allophant)

只用音频加普通文本/G2P 训练有可能继续偏向字典读法，压平我们关心的异音。ZIPA 论文自身也报告过对实际变体转写不足、预测向规范读法靠拢的现象；因此这里的核心投入是**真实录音对应的细节标签**，不能只增加音频小时数。[ZIPA 论文，第 7 节与 Figure 2](https://aclanthology.org/2025.acl-long.961.pdf)

训练硬件、batch、学习率和轮次在片段长度、实际可训练条数、输出词表确定后，以小批试跑测显存/时间再定；不在当前 Intel macOS 对照环境中把不支持的运行组合当作训练基准，也不预估无依据的提升百分比。

## 6. 数据划分与验收

- 先在原始轨道解码 PCM 上确定片段边界，保留原文件哈希、帧范围和上下文；衍生 16 kHz mono 训练副本。长词表不能按词数平均切，VAD 也只给边界候选。不得强降噪抹掉短闭塞/爆破。
- 同一句、相邻裁剪、同一词的重复、强弱读对照、同模板句族按组划分。先分组再生成增强版本，避免相同声音或近同句跨 train/dev/test。
- 教材内部先做按轨道/句族隔离的适配评估；没有已核验说话人元数据前，不声称 speaker-disjoint。最终另用不同说话人的自然语流与真实学习者录音评估迁移。专业示范与学习者发音分别报告。
- 可将首批审校工作量暂定为 **200–300 个短片段**；三类争取各覆盖约 30 个阳性与 30 个匹配语境的反例，允许一条含不同目标。这是启动实验的取样目标，不是已发现数量或上线充分样本量。素材不足就按缺口补录，不能让规则制造反例。
- 原有首轮/第二轮公开样本继续作为开发诊断；已经看过模型结果并参与决策的项目不能包装为未见最终测试。独立测试先冻结再训练，不用测试集选阈值。
- IPA 报统一 phone tokenization 的 PER、目标音段/附标混淆和新增/漏掉 [ɾ] 等错误；同时保留宽、窄两个口径，防止“删除细节后分数更好”。
- 每个现象独立报告 precision、recall、F1、弃权率和有效覆盖；区分“给定人工目标窗口”与端到端定位表现。阴性必须是相同适用语境中的实际非目标实现，不拿不适用句子充数。
- 新模型需在冻结材料上比基线改善，且不以大幅增加误报换召回；错误集中在哪些说话人/音段也要报告。当前几条样本只能供开发，不提供泛化准确率。
- 只有通过相应类别验证后，才考虑将预测转成 Sound 可点击证据。保持 GA 12 类、Vowel length 条件提示和现有评分契约，训练实验不自动改变用户端。
