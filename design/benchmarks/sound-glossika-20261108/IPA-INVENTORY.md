目录可用于检查编码、查名称和生成覆盖报告。GA 注音范围单独标记；非 GA 声调、搭嘴音等保留在参考目录，不因“官方表里存在”就自动扩展训练头。所有合法 IPA 组合不是一张有限列表，目录也不是完整音系分析器。

## 教材记法的处理

教材文件 SHA-256：`d15e475279d349eef6852a83f5eef6e95089487f1a8ad3c6dfe67d7a31e2bd09`。页码均为 PDF 的 1-based 页码。

| 原记法 | 新处理 | 依据与边界 |
|---|---|---|
| `⁼` | 在本教材适配器中转换为 `˭` | 教材第 5 页定义为不送气；网站 extIPA 与 Unicode U+02ED 同义。绝不能转换为表示无可闻爆破的 `◌̚`。 |
| `ʴ` | 保留，记录为教材的元音相关 R 修饰 | 第 6、14 页说明其 R 音用法；网站补充项与 Unicode 均有此字符。主表 `˞` 表示 rhoticity，但不能把所有 R 离滑都无条件改写为同一个音质。 |
| `ʱ` | 保留，不改成 `◌̤` | 第 12、14 页用于有声、弱的 H 伴随音；网站补充项收录。伴随音与音段本身的气声发声方式不能直接合并。 |
| 元音后的 `ʲ / ʷ` | 保留教材读法，附注其滑音记法 | 第 6–8 页有具体解释。不能仅按主表的“腭化/唇化”名称，把这些全部生成辅音次要调音事件。 |
| `ʧ ʤ ʦ ʣ` | 普通单独连字展开成 `t͡ʃ d͡ʒ t͡s d͡z` | 已带结合弧的 `t͡ʧ` 不自动去重或猜读法。 |
| `d̪ / ð` | 保持不同 | 前者是齿化塞音，后者是齿擦音；教材第 9 页明确区分。差异可能是实际发音差异，不能为降低错误率而当作排版差异消除。 |

`glossika-surface-v2` 保留原始听辨字符串，单独保存转换记录、表层参考和模型输入。使用 Unicode **NFD 规范分解**使附标显式化，禁止 NFKC 将上标降成普通字母。表层参考保留结合弧；为兼容当前 CTC 词表，仅在明确命名的 CTC 投影中移除空白和可选结合弧。原始空格不被冒充为经过对齐的词边界。

## 原模型能表达哪些符号

检查的是本地已固定版本的实际 token 表。ZIPA small / large 共用同一词表。下表的“独立项”仅说明可直接编码；既不证明对应录音识别正确，也不证明现象检测已可用。

| 符号 | Wav2Vec2 原词表 | ZIPA 原词表 |
|---|---|---|
| `ɾ ʔ` | 有独立项 | 有独立项 |
| `ɦ ʷ` | 缺失 | 有独立项 |
| `ː ◌̪ ◌̩ ʰ` | 只出现在部分复合 token 中 | 有独立项 |

不能把“某个复合 token 内含附标”当作“支持给任意音段加这个附标”。覆盖报告分别列出独立 token、精确序列编码、复合 token 内出现，以及未知的实际识别能力。

`◌̚`、`◌̥`、`◌̩` 等已经进入参考目录；本批没有相应监督例子时不凭空给训练头加未监督的输出。等后续经确认样本出现，使用同一个保留旧 ID 的扩展程序按需增补。

## 与 Sound 12 类的关系

| 产品类别 | 可用的音串/符号线索 | 还需什么才能判定现象 |
|---|---|---|
| Linking | `‿` 可记录无断开 | 跨词对齐与声学证据；没有静音不自动等于连读 |
| Coalescence | 如 `t͡ʃ / d͡ʒ` | 原本 `/t,d/ + /j/` 的语境，排除原生塞擦音 |
| Assimilation | 如 `/n/` 对应 `m / ŋ` | 对应词位、邻音、原读法与竞争实现 |
| Weakening | 如弱元音 `ə` | 原词音、重音与当前元音；`ə` 本身不是弱化事件 |
| Reduced forms | 整个短语的实际音串 | 词组对应及允许的变体，不是新增一个 IPA 符号 |
| Elision | 音段缺失的对应关系 | 对齐与可靠的阴性证据；缺失不是一个要加入 IPA 词表的发音符号 |
| T/D tap | `ɾ` | 对应 `/t,d/` 词位、局部证据和本轮限定的词内范围 |
| Glottalization | `ʔ`、相关声门化附标 | 区分替代、加强与其他来源的声门音 |
| Unreleased | `◌̚` | 塞音的局部闭塞与释放证据；不能用不送气替代 |
| Syllabic | `◌̩ / ◌̍` | 实际音节结构，区别于带弱元音的实现 |
| Voicing change | `◌̥ / ◌̬` 等 | 对应音段与局部浊音证据 |
| Vowel length | `ː / ˑ / ◌̆` 可表达时长区别 | 控制语境，检验词尾清浊条件导致的相对长短；不能仅凭长音号判定教学目标已达到 |

因此需要分开保存**音段及附标、源记法、词位/时间和现象判断**。参考目录完善不会自动完成这 12 类检测。
