# Wav2Vec2Phoneme 原权重 IPA 微调结果

2026-11-09。已完成两个数据版本、每版三个随机种子的输出头监督微调。**当前评分下，两版都没有改善独立录音表现，继续保留原模型作为基线。** 本轮没有训练语音现象分类头，也没有更新编码器或线上模型。

## 实验和对比

原模型为已固定版本的 `facebook/wav2vec2-lv-60-espeak-cv-ft`。保留原 392 个 token ID 和对应输出头权重，追加 24 个训练所需字符，共 416 项；只有新增行随机初始化。训练目标完整保留 Glossika 原记法。原大模型文件的 SHA-256、原模型在全部 562 条训练／外部录音的输出都在结束时再次验证一致。

两个版本分别从原权重开始，不相互接续：

- 50 条已有人工核对的数据：每种子 40 轮、320 次更新，共 960 次。
- 549 条完整教材监督数据：50 条核对 + 499 条自动关联，每种子 40 轮、3,160 次更新，共 9,480 次。

固定学习率 0.0001、AdamW、batch 7；编码器冻结、无 dropout／增强／语言模型。共六个保存并重载验证的模型头。相同轮数不代表相同更新步数，不能把差异全部归因于新增数据质量。

5 条开发录音仅作报告；没有选择最优轮次，也没有根据外部结果追加训练。8 条外部录音与训练材料分开，但已在此前实验曝光，本轮属于回归对比，不是新增盲测。没有新增合格盲测标注，未完成的原听辨草稿及录音保持原样。

| 版本 | 外部基础 IPA 单位错误率 | 外部兼容记法字符错误率 | 外部原记法字符错误率 |
|---|---:|---:|---:|
| 原模型 | **19.02%** | **26.99%** | **26.99%** |
| 50 条微调 | 19.67% | 27.46% | 27.46% |
| 549 条微调 | 31.48% | 48.86% | 49.91% |

微调行是三个种子的均值，完整标准差与逐句输出保存在 JSON。549 条版本的训练集原记法字符错误率从 52.81% 降至 20.14%，但八条外部录音的基础单位错误率均上升。50 条版本在本身训练子集从 45.64% 降至 31.36%，外部基本持平且略差。当前不能将训练拟合改善称为真实录音识别提升。

## 评分口径统一到哪里

规则在训练前写入并冻结 `SCORING-CONTRACT.json`。前后输出应用完全相同的规则，人工原标注、模型原输出和 Glossika 目标都未被改写。

1. **原记法 CER**：NFC，仅移除空白和转写外括号。
2. **兼容记法 CER**：显式对应 `⁼/˭`、`ṇ/n̩`、`ʧ/t͡ʃ` 等旧连字、`g/ɡ`，使用 NFD，保留附标／重音／结合弧。
3. **基础 IPA 单位错误率**：在兼容记法上移除附标、重音、长短和结合弧，塞擦音作为两个单位计数；其余音质差异保留。这是声明了规则的诊断投影，不是通用 PER。

不将 `d̪/ð`、`t̪/θ`、`r/ɹ`、`ɫ/l`、`ʴ/ɚ`、`eʲ/eɪ` 或 `oʷ/oʊ` 擅自合并。外部宽式标签与教材窄式记法的所有差异尚未解决；缺少附标不表示听辨确认其未发生。因此不能用本次字符误差推算附标准确率，更不能推算 Sound 事件准确率。原始结果保留，后续可以在明确确认的另一评分契约下重算，并注明这些数据已用于分析。

本次基础指标与上一轮探针的音段计数不同；上一轮也使用随机新头，不能把本次 19.02% 与上一轮 39.69% 当成一次训练带来的改善。

执行入口（默认目录已存在，不会覆盖；重跑必须指定新目录）：

```sh
PYTHONPATH=apps/api .cache/sound-pilot/venv/bin/python -m scripts.sound_pilot.ipa_adapt --out /absolute/path/to/new-run
```

恢复一个训练后的模型时，先用项目 `glossika_finetune.load_base` 加载固定原模型，再创建 `Linear(1024, 416)`，严格载入对应的 `reviewed-<seed>.pt` 或 `full-<seed>.pt` 替换 `lm_head`，更新 `config.vocab_size`。词表必须使用该包 `CONFIG.json` 中的 `vocab`；保留原特征提取器，用 `glossika_finetune.decode` 做 CTC 解码。加载前验证 `EVALUATION-RELEASE.json` 的 checkpoint 哈希。不使用上一轮 62 项探针词表。

下一步应复核训练／外部记法与短句到长句的迁移差异，并补齐新的、同口径独立 IPA 标注。此次结果不支持直接替换原模型，也不能仅凭这两个版本就断定 499 条新增数据有误。没有根据这批已曝光录音继续调学习率或解冻层数。

验证：十项新增回归测试覆盖词表 ID 保留、最长 token、字面目标往返、显式别名、真实音质差异和未完成结合弧的计分。三个真实录音的缓存特征与原模型现场推理一致；六个 checkpoint 重载后全部预测一致；原权重文件及 562 条原输出复核一致。`pnpm lint`、`pnpm build` 通过。第一次并行测试有一个既有 MFA 心跳时序断言失败（2,170 通过）；训练结束后未改该测试或产品代码，完整 `pnpm test` 重跑 2,171 项 API 测试全部通过，Web／Extension 通过。
