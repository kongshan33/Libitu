# Wav2Vec2 首轮小规模微调

2026-11-08。按用户要求，用全部 49 条已确认候选完成一轮真实参数更新，再对比同一批录音和另外 12 段既有开发录音。**训练标签拟合明显改善，但额外录音出现可疑退化；当前权重只保留为实验产物，不替换产品模型。**

## 实验实际做了什么

| 项目 | 本轮配置 |
|---|---|
| 底座 | `facebook/wav2vec2-lv-60-espeak-cv-ft`，固定原有 revision / 权重 |
| 方法 | **CTC 监督微调，仅训练输出层**；不是全参数微调、LoRA 或强化学习 |
| 数据 | Glossika 49 句，合计 **46.730375 秒**；第 23 句仍排除 |
| 词表 | 392 → 399，保留全部原 token ID；新增 7 行，已有输出行也参与本轮更新 |
| 可训练参数 | 408,975；语音编码器全部冻结 |
| 训练 | 40 epochs，batch 7，**280 次 AdamW 更新** |
| 学习率 | 峰值 0.0005，14 步 warmup，之后线性衰减；weight decay 0.01，梯度裁剪 1.0 |
| 随机与设备 | seed 20261108，CPU / FP32，确定性操作，2 线程 |
| 正则/增强 | 无音频增强，编码器 eval，关闭 dropout；第一轮固定基线配置 |
| 权重选择 | 事先固定最后一轮；没有根据额外 12 段挑 epoch 或调参 |

使用冻结编码器提取真实音频特征后训练线性输出层，避免每一轮反复运行同一编码器。特征提取约 46.37 秒，训练与权重重载检查约 4.02 秒，含额外录音推理等总计约 72.76 秒；这些是本机单次运行时间，不作为硬件/模型速度排名。

方法与 API 依据：[Transformers 4.41.2 Wav2Vec2](https://huggingface.co/docs/transformers/v4.41.2/en/model_doc/wav2vec2)、[PyTorch CTC loss](https://docs.pytorch.org/docs/stable/generated/torch.nn.CTCLoss.html)。实际冻结范围和参数更新由本地脚本与 checkpoint 记录证明。

## 49 句训练录音的前后结果

这些数值是**训练集拟合诊断**，不是独立测试准确率、PER 或 Sound 现象 F1。目标采用同一个 `glossika-surface-v2` CTC 投影；比较时展开旧连字、去空白和可选结合弧，按 NFD Unicode 字符计算编辑距离，保留其他发音细节。655 个参考字符不等于 655 个音素。

| 诊断 | 微调前 | 仅扩词表、未训练 | 微调后 |
|---|---:|---:|---:|
| 字符编辑次数 | 261 | 261 | 122 |
| 字符差异率（655 个参考字符） | **39.85%** | **39.85%** | **18.63%** |
| 整句投影标签完全一致 | 0 / 49 | 0 / 49 | 5 / 49 |
| 替换 / 删除 / 插入 | 109 / 146 / 6 | 109 / 146 / 6 | 20 / 95 / 7 |

46 句字符编辑距离降低，3 句持平，0 句升高。训练平均 CTC loss 从第 1 轮 3.8320 降到第 40 轮 0.6146。三个输出条件使用相同音频和解码方式；单独扩词表没有产生这次改善。

例：“What does it do”

| 来源 | IPA |
|---|---|
| 用户确认的参考投影 | `wʌɾʌːzɪʔduːʷ` |
| 原模型 | `wʌɾʌzɪtduː` |
| 微调后 | `wʌɾʌzɪʔduː` |

这句开始输出参考中的声门塞音，仍漏了部分长度/滑音细节。不能因为出现 `ʔ` 就自动把整句的 Glottalization 判为检测正确。

| 符号 | 参考中出现次数 | 原模型输出次数 | 微调后输出次数 |
|---|---:|---:|---:|
| `ɾ` | 23 | 17 | 24 |
| `ʔ` | 19 | 0 | 14 |
| `ɦ` | 4 | 0 | 3 |
| `ʱ` | 5 | 0 | 0 |
| `ʴ` | 6 | 0 | 1 |
| `ʷ` | 26 | 0 | 2 |
| `ː` | 110 | 55 | 89 |
| `˭` | 3 | 0 | 0 |
| `◌̪` | 21 | 0 | 13 |

这是未定位的字符串计数，不是召回率；`ɾ` 输出 24 次也可能包含误报。特别是新增 `ʱ`、`˭` 仍未出现，`ʷ`、`ʴ` 仍很少。词表覆盖与学会识别依然是两件事。

## 12 段未参与本轮训练的录音

使用原有 round-two 的完整原句，包含参考音和学习者音。训练/额外对照的文件哈希与 ID 均无重叠。额外录音在参数更新结束后才输入本次模型，不参与 loss、梯度、学习率或 checkpoint 选择。它们此前用于比较底座，**属于既有开发材料，不是全新盲测集**；也没有完整的人审 IPA，故不计算前后准确率。

12 段输出都发生了变化，部分变化是明显值得回听的退化信号。例如：

“Gad, your letter came just in time.”

- 原模型：`ɡædjɔːɹlɛɾɚkeɪmdʒʌstɪntaɪm`
- 微调后：`ɡædjɪːlɛɾəkeɪmdʒʌsɪntsaːm`

这里 `your` 对应片段、R 音、句尾 `time` 对应音串都变了；不能把新增长音或附标视为改善。其他额外样本也出现 `aɪ` 变为 `aː`、`ð` 变为 `d`、额外的声门音/塞擦序列等变化。**这是根据前后音串发现的疑似过拟合/原能力损失信号，不是经过新一轮人工听辨得到的错误率。**

这轮支持的结论：49 条监督足以让输出头学习一部分教材标签；不足以证明对新说话人或新语境更可靠。后续优先扩充有代表性的、可用于训练的多说话人/多语境材料，并加入保留原模型能力的约束，再比较不同适配方法。不要单纯继续增加这 49 句的训练轮数。
